# KurdChat Web Sitesi

Bu klasör GitHub Pages için hazırlanmıştır.

## Dosyalar
- `index.html` — ana sayfa
- `style.css` — tasarım
- `script.js` — küçük JavaScript
- `CNAME` — `kurdchat.com.tr` özel domain ayarı
- `kurdchat.apk` — sonradan buraya release APK konulacak

## Yayına alma
GitHub'da public bir repository oluşturup bu dosyaları yükleyin.
Settings → Pages → Deploy from a branch → main / root seçin.
Custom domain kısmına `kurdchat.com.tr` yazın.

APK hazır olduğunda aynı klasöre `kurdchat.apk` adıyla koyun.

## Logo
`kurdchat-logo.png` KurdChat logosunun şeffaf arka planlı sürümüdür.
